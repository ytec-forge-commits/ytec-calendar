# Koyomado

Y-TECが開発する、Windowsのデスクトップへウィジェットのように置いて使うシンプルなポータブル型カレンダーです。予定データは暗号化せず、実行ファイルと同じ場所の `data` フォルダーへ保存します。アプリのフォルダーごとUSBメモリやGoogle Driveへ置いて持ち運べます。

## 主な機能

- 月カレンダーで予定を確認、追加、編集、削除
- 誕生日や記念日を、毎年同じ月日に自動表示
- 予定を別の日へドラッグして移動、Ctrlキーを押しながらドラッグしてコピー
- カレンダー上の予定を右クリックでコピーし、任意の日へ右クリックで即時貼り付け
- 予定のある日を選ぶと、その日の予定を一覧表示
- 土曜・日曜・日本の祝日を色分けし、祝日名を表示（オフライン）
- 終日予定と時刻付き予定
- LINE Seed JPで統一した読みやすい表示
- 予定を見分けやすい6色の色分け
- 心安らぐ背景テーマ8種
- ウィンドウ位置とサイズの保存
- デスクトップへ置きやすい960×620の既定サイズ（最小高さ600px）
- 開閉状態を記憶する折りたたみ式サイドバー
- サイドバー表示中は最小幅806px、非表示中は375pxまで縮小可能
- 起動中はタスクバーに表示せずタスクトレイへ常駐し、トレイから表示・終了可能
- Windows起動時の自動起動（設定で切り替え）
- 更新前バックアップ付きの版管理JSON保存

印刷、PDF、外部API、クラウド同期、認証、アクセス解析は含みません。

## 初回の使い方

1. 配布ZIPを、今後使う場所へ展開します。
2. `koyomado.exe` を起動します。
3. 右上の歯車から「Windows起動時に自動起動」をONにします。
4. カレンダーをデスクトップ上の好きな位置とサイズへ調整します。次回からその位置で開きます。

右上の閉じるボタンでは画面だけを隠し、アプリはタスクトレイに残ります。完全に終了するときは、トレイのアイコンを右クリックして「終了」を選んでください。

自動起動をONにした後でアプリのフォルダーを移動するときは、移動前にいったんOFFにし、移動後の実行ファイルからONにし直してください。

## 開発

```powershell
npm install
npm run tauri:dev
```

Web画面だけを確認するときは `npm run dev` を使えます。この場合はブラウザーのlocalStorageへ合成データを保存し、自動起動などのWindows機能は動きません。

## ポータブルZIP

```powershell
npm run tauri:portable
```

`release/koyomado-v<version>-windows-portable.zip` を生成します。初回はZIPを展開して `koyomado.exe` を起動してください。更新時は既存の `data` フォルダーを残し、実行ファイルだけを差し替えます。

配布ZIPには、画面例付きの `Koyomado操作説明書.pdf`、利用条件の `LICENSE.txt`、更新履歴の `CHANGELOG.md`、第三者ライセンス案内の `THIRD_PARTY_NOTICES.md`、LINE Seed JPのライセンス全文を同梱します。操作説明書は公式紹介ページからも閲覧できます。

操作説明書を更新するときは、Windows標準のBIZ UDPゴシックとReportLabを利用して生成します。

```powershell
python scripts/generate-operation-manual.py
```

### Y-TEC Calendarから更新する場合

1. 旧アプリの設定でWindows自動起動をOFFにし、タスクトレイから終了します。
2. 旧アプリと同じフォルダーへ `koyomado.exe` を置き、既存の `data` フォルダーはそのまま残します。
3. `koyomado.exe` を起動して予定を確認した後、不要になった `ytec-calendar.exe` を削除します。
4. 必要に応じてKoyomadoの設定からWindows自動起動をONにし直します。

以前の保存形式（version 1）は初回起動時にversion 2へ自動移行します。移行前の内容は `calendar-data.backup.json` に残るため、既存予定を入力し直す必要はありません。

Google Drive上で使う場合、同じフォルダーを複数PCから同時に開かないでください。同期途中の競合解決は行いません。

祝日データはアプリへ同梱しており、起動時の通信はありません。現在の内蔵データ範囲は1970年から2050年です。祝日法の改正や2051年以降へ対応するときは、アプリの祝日データ依存を更新します。

## 保存ファイル

- `data/calendar-data.json`: 予定と外観設定
- `data/calendar-data.backup.json`: 直前の保存内容
- `data/window-state.json`: ウィンドウ位置とサイズ
- `data/window-state.backup.json`: 直前の位置情報

予定の削除は画面上から見えなくするソフトデリートです。削除済みデータは `deletedEvents` に残ります。
